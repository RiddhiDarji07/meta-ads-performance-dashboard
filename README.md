# 📊 Meta Ads Performance Dashboard

## 1. Project Title / Headline
Interactive Power BI Dashboard for Analyzing Facebook & Instagram Meta Ads Performance, Engagement, and Marketing Insights.

---

# 2. Short Description / Purpose

The Meta Ads Performance Dashboard is designed to analyze and monitor advertising campaign performance across Facebook and Instagram platforms. The dashboard helps marketers and businesses track engagement, conversions, audience reach, and overall campaign effectiveness to make data-driven marketing decisions.

---

# 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 Power BI Desktop – Main data visualization platform used for creating interactive reports and dashboards.
- 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, KPI calculations, dynamic visuals, and conditional logic.
- 🔗 Data Modeling – Relationships established between tables to enable filtering, drill-down analysis, and cross-visual interactions.
- 📁 File Formats – `.pbix` used for dashboard development and `.png` used for dashboard previews and screenshots.

---

# 4. Data Source

### Data Source:
The dataset used in this project contains Meta advertising campaign data collected from Facebook and Instagram ad platforms.

### Dataset Includes:
- Campaign Name
- Platform (Facebook / Instagram)
- Impressions
- Reach
- Clicks
- Engagement
- Conversions
- Ad Spend
- CTR (Click Through Rate)
- ROI Metrics

### Data Structure:
The data is structured in tabular format where each row represents a unique ad campaign and columns represent different performance metrics and KPIs.

---

# 5. Features / Highlights

## 📌 Business Problem

Businesses running Meta advertisements often struggle to track campaign performance across multiple platforms and identify which campaigns generate the highest engagement and conversions.

Without proper visualization, analyzing large volumes of marketing data becomes difficult and time-consuming.

---

## 🎯 Goal of the Dashboard

The primary goal of this dashboard is to:
- Monitor ad campaign performance
- Compare Facebook and Instagram engagement
- Analyze marketing KPIs
- Identify high-performing campaigns
- Support better business and marketing decisions

---

## 📈 Walkthrough of Key Visuals

### 🔹 KPI Cards
Displays important metrics such as:
- Total Reach
- Total Impressions
- Total Clicks
- Conversion Rate
- Engagement Rate
- Total Ad Spend

### 🔹 Platform Performance Analysis
Compares Facebook and Instagram campaign performance using charts and visual comparisons.

### 🔹 Engagement Analysis
Shows audience interaction trends and identifies campaigns with the highest engagement.

### 🔹 Conversion Tracking
Analyzes which campaigns generate better conversion results and ROI.

### 🔹 Spend vs Performance
Visualizes the relationship between advertising spend and campaign outcomes.

---

## 💡 Business Impact / Insights

- Helped identify the most effective advertising platform
- Improved understanding of customer engagement behavior
- Enabled better budget allocation decisions
- Supported performance tracking using real-time KPIs
- Simplified marketing data analysis through interactive visuals
